## Main illustration

Output: `public/images/models-layer.png`.

Prompt:

> Create one premium abstract editorial illustration for the Web Models API website. Landscape composition 3:2. A large, precise isometric navy rectangular platform (#0B1B3A) with two offset layers, and a smaller crystalline stacked cube above it, with three translucent ice-blue and vivid indigo (#2431C4) levels. A small peach sphere sits toward the lower left, a small blue sphere toward the right. Fine analog stipple grain throughout the geometric objects, sophisticated Swiss technical editorial print texture. Flat orthographic view, clean sharply cut edges, no shiny plastic, no dramatic shadows, no photorealism. Balanced asymmetrical composition with generous breathing room. All elements fully inside frame with safe margins. Uniform light blue-gray background exactly #DCE3EE, running to every edge, so the asset blends into a web page of that color. The palette is icy blue, indigo, navy, subtle peach; quiet architectural visual, restrained, confident, minimal. No text, no letters, no numbers, no logos, no website mockup, no rounded UI cards. The piece symbolizes models becoming part of the browser platform.
